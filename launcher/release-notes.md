## Bed Defense 모드 v0.2.0-alpha.9+26.3 — 조용한 게임 시작 초기화
- **게임 시작 3초 카운트다운:** 참가자들이 모험 모드로 전환됩니다. 3→2→1 화면/소리는 기존과 같습니다.
- **카운트다운 완료 후:** 정상적으로 새 챌린지 시작 시 아이템(인벤토리, 핫바, 방어구, 보조 손, 커서)을 제거하고 **서바이벌 모드**로 변환합니다.
- **채팅 메시지 없음:** 게임모드 변경이나 아이템 제거에 대한 바닐라 명령어 메시지가 출력되지 않습니다. 기존 챌린지 시작 안내는 유지합니다.
- **안전한 중단:** 시작 실패나 카운트다운 중단 시 아이템을 제거하지 않고 기존 게임모드를 복원합니다.
- **동일 월드 다시 시작에도 적용:** 월드 건축물과 엔더 상자·경험치는 보존되지만 **새 도전 시작 시 참가자 인벤토리가 삭제됩니다**.
- 이전 어려움 레이드 랜덤 편성/공성 밸런스(alpha.8) 등 게임 규칙과 기존 프로필 설치·검증·롤백 엔진은 그대로 유지됩니다.

### 기존 런처 업데이트
Minecraft와 공식 런처를 종료하고 Windows Bed Defense Launcher에서 **업데이트 조회 → 업데이트 설치**를 누르세요. 기존 프로필의 Bed Defense 모드 JAR만 업데이트합니다.
