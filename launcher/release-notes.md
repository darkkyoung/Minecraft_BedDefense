## Bed Defense 모드 0.2.0-alpha.7+26.3 — 어려움 레이드 실전 테스트
- **어려움 전용 편성:** 첫날 12마리 → 10일차 58마리 → 50일차 107마리 → 100일차 125마리 (플레이어당, 상한 150)
- **10일차부터 신속 III**, 아기 좀비 별도 편성. 초반 화염 저항, 수중 이동 보정, 후반 무기·방어구 강화.
- **빠른 공성:** 어려움 채굴 및 설치 속도 가속. 쉬움 기존 몬스터 편성 유지·채굴 시간 50% 단축.
- **기존 도전 보호:** 업데이트 전 시작한 도전은 이전 레이드 프로필을 유지합니다. 새 난이도를 시험하려면 새 임시 월드에서 새 챌린지를 시작하세요.
- **성능/체감 검증 필요:** 몹 AI의 복잡한 수직 지형·수중 경로 및 장시간 100일 플레이는 실제 Minecraft에서 확인해야 합니다.

### 런처 업데이트
기존 Fabric 26.3 프로필에서 **업데이트 조회 → 업데이트 설치**로 모드 JAR만 교체합니다. 기존 세계, 타 모드, 설정, Fabric Loader/API를 임의로 변경하지 않습니다.
실행 중인 Minecraft를 먼저 종료하세요.

[테스트 절차](https://github.com/darkkyoung/Minecraft_BedDefense/blob/main/docs/HARD_MODE_ACCEPTANCE.md)

### 런처 자체
Launcher 0.4.0의 다크/라이트 테마, 기존 Fabric 프로필, 체크섬·백업·복구 기능은 그대로 유지됩니다.
