## Bed Defense 모드 0.2.0-alpha.13+26.3 — 스폰 침대 복구 비콘

- **스폰 침대 파괴 시 원래 위치에 단일 복구 비콘 1개가 생성됩니다.** 광물 피라미드 없이 녹색 빛기둥만 솟고, 일반 비콘의 버프·강화·기존 메뉴는 존재하지 않습니다.
- 복구 비콘은 일반·크리에이티브 채굴과 TNT·피스톤 이동을 막고 아이템으로 획득할 수 없습니다. 일반 마인크래프트 비콘 기능은 변경하지 않습니다.
- **소유자 전용 3×3 복구 화면:** 필요한 아이템이 50% 정도 흐린 안내 아이콘으로 표시됩니다. 안내 아이템은 꺼낼 수 없고, 직접 재료를 해당 칸에 넣어야 합니다. 부분적으로 넣고 종료한 재료는 반환합니다.
- **1차 복구:** 가운데 일반 침대 1개 + 나머지 에메랄드 8개 → 원래 자리에 HP 25로 스폰 침대 복원.
- **2차 복구:** 가운데 일반 침대 1개 + 나머지 에메랄드 블록 8개 → 원래 자리에 HP 50으로 복원.
- **3번째 파괴 후 복구 불가.** 플레이어 UUID·복구 횟수·침대 위치/방향은 월드 서버에 저장되며, 타인이 직접 복구할 수 없습니다. 파괴 후 리스폰은 계속 불가능합니다.
- **설치된 스폰 침대의 수리는 에메랄드만 가능합니다.** 1개당 HP 1이며 다이아몬드는 더 이상 수리 재료가 아닙니다.
- 현재 보통 난이도 v1 등 기존 레이드 밸런스와 시작 카운트다운·HUD 기능은 유지합니다.

### 기존 런처에서 설치
Minecraft와 공식 런처를 종료한 뒤 Bed Defense Launcher에서 **업데이트 조회 → 업데이트 설치**를 이용하세요. 기존 Fabric 26.3 프로필의 모드 JAR만 교체합니다. 사용자의 다른 모드·월드·설정 파일은 삭제하지 않습니다.
