## Bed Defense 모드 0.2.0-alpha.11+26.3 — 물속 좀비 레이드 추적 오류 수정

- **레이드 좀비가 드라운드로 변하면서 레이드가 조기에 종료되는 오류 수정.**
- 레이드에 등록된 좀비·허스크는 물속에 오래 있어도 다른 몹으로 변환되지 않습니다. 기존 UUID·레이드 추적·남은 몬스터 수·아침 정산이 유지됩니다.
- **일반 야생 좀비·허스크는 기존 마인크래프트처럼 물속에서 변환됩니다.** 편성표에 포함된 원래 드라운드는 영향을 받지 않습니다.
- 기존 환영 채팅 확장, 게임 시작 3초 카운트다운, 인벤토리 초기화, 난이도 밸런스와 공성 속도는 유지했습니다.
- 자동 서버 GameTest로 물속 변환을 확인했습니다. 실제 레이드 추격 AI와 여러 지형에서의 장시간 플레이는 사용자 PC 실전 검증이 필요합니다.

### 런처 업데이트
Minecraft와 공식 런처를 종료하고 **Bed Defense Launcher → 업데이트 조회 → 업데이트 설치**를 이용하세요. 기존 Fabric 26.3 프로필의 Bed Defense JAR만 교체하며 월드·다른 모드·설정은 보존합니다.
