## Bed Defense 모드 v0.2.0-alpha.12+26.3 — 보통 난이도 v1 추가

- **보통 난이도가 독립된 레이드 밸런스를 갖습니다.** 쉬움과 어려움 사이의 중간 몬스터 수, 다양한 몬스터 편성과 단계별 강화 효과를 적용했습니다.
- 밤마다 한 번 랜덤 추첨해 저장: 보통 1일차 **6~8마리**, 2일차 **9~11**, 10일차 **25~31**, 20일차 **34~42**, 50일차 **53~65**, 100일차 **84~102마리** (참가자 1명당). 10일 단위 대장은 총원에 포함됩니다.
- **20일차부터 아기 좀비**, **25일차부터 일부 신속 III**, 51일차부터 적격 몹의 신속 III 보장. 화염 저항·무장·수중 이동·몹 종류가 단계적으로 강화됩니다. 아기 좀비는 신속 III 중복 적용에서 제외합니다.
- **보통 공성 속도(초기):** 흙 1.5초 / 나무 3.4초 / 조약돌 8.5초 / 흑요석 34초. 블록 설치 간격 0.9~1.5초, 공성 반응 약 1.5초. 쉬움·어려움의 기존 수치는 그대로입니다.
- **진행 중 난이도 변경 불가:** 이미 진행 중이던 보통 도전은 이전 밸런스를 유지하며, 새로운 보통 v1은 신규 도전이나 종료 후 [다시 시작]에서 보통을 선택할 때만 적용됩니다.
- 활성 개체 한도 때문에 등장하지 못한 보통 몬스터는 아침 HP 패널티에서 제외됩니다. 이전 침대 규칙·차원 사망·물속 좀비 변환 방지·환영 채팅·시작 인벤토리 초기화는 변경하지 않았습니다.
- 자동 Minecraft 26.3 서버/클라이언트 검증과 실제 PC에서의 100일 체감 밸런스 검증은 별도입니다.

### 기존 런처에서 모드 업데이트
Minecraft와 공식 런처를 종료하고 Bed Defense Launcher에서 **업데이트 조회 → 업데이트 설치**를 선택합니다. 기존 Fabric 26.3 프로필의 Bed Defense 모드 JAR만 교체하며, 월드·설정·다른 모드를 임의로 변경하지 않습니다. 런처 EXE는 다시 받을 필요가 없습니다.
