## Bed Defense Launcher 0.4.0
- 다크 · 라이트 테마와 마지막 선택 기억
- 침대를 지키는 장면의 전용 배너
- 더 큰 설치 · 실행 버튼과 간결한 환경 정보
- 붉은 블록 침대 모양의 Windows 아이콘

### 보존되는 기능
기존 Fabric 프로필 선택, 호환성 검사, SHA-256 검증, 롤백, 다른 모드·월드·설정 보존 및 런처 자체 업데이트는 유지합니다.
모드 게임 코드와 밸런스는 변경하지 않았습니다.

### 사용 안내
헤더의 라이트/다크 버튼으로 화면을 전환합니다. 폴더 변경과 호환성 정보는 ‘폴더 설정 · 환경 상세’에서 펼칩니다.

[실제 Windows 화면과 PC 확인 절차](https://github.com/darkkyoung/Minecraft_BedDefense/blob/main/docs/LAUNCHER_L3.md)
