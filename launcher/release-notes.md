## Bed Defense Launcher 0.3.0
- 설치 환경과 버전 정보를 한눈에 확인하는 새로운 다크 테마를 적용했습니다.
- 기존 Fabric 프로필 선택, 전체 게임 경로 복사 및 접이식 배포 내역을 제공합니다.
- 설치·업데이트 버튼을 하단에 고정하고 실제 다운로드 진행률을 표시합니다.
- 침대와 방패를 결합한 전용 Windows 앱 아이콘을 적용했습니다.

### 보존되는 기능
기존 Fabric 설치, SHA-256 검증, 롤백, 다른 모드·월드·설정 보존 및 런처 자체 업데이트는 유지합니다.
모드 게임 코드와 밸런스는 변경하지 않았습니다.
