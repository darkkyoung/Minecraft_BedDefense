## Bed Defense 0.2.0-alpha.8+26.3 — 어려움 레이드 밸런스 조정
- **어려움 몬스터 수 범위 추첨:** 매일 밤 한 번만 추첨하며 월드 데이터에 저장됩니다. 1일차 7~12, 2일차 10~17, 10일차 31~58, 30일차 49~90, 50일차 66~107, 100일차 88~125마리 (플레이어당, 원래 어려움 최대치 유지).
- **어려움 공성 완화:** 1~10일차 첫 단계 흙 1초, 판자 2초, 조약돌 5초, 흑요석 20초, 블록 설치 간격 0.75~1초. 기존 상한·채굴 제한은 그대로입니다.
- 신속 III의 10일차 도입, 아기 좀비, 화염 저항, 무장과 수중 이동 보정은 유지합니다.
- **기존 도전 보존:** alpha.7에서 이미 진행 중인 어려움 챌린지는 기존 고정 편성·공성 속도를 유지합니다. 새 밸런스는 새 월드/새로 시작한 도전에서만 적용됩니다.
- 실플레이·고난도 지형 공성·수중 추적 AI·100일 밸런스는 아직 사용자 PC 검증 대상입니다.

### 기존 런처에서 업데이트
Minecraft와 공식 런처를 종료하고 Windows Bed Defense Launcher에서 기존 **Fabric 26.3 프로필**을 확인한 후 **업데이트 조회 → 업데이트 설치**를 선택하십시오. EXE를 다시 받을 필요가 없으며 모드 JAR만 업데이트하고 월드·기타 모드·설정·프로필은 보존합니다.

[실전 테스트 체크리스트](https://github.com/darkkyoung/Minecraft_BedDefense/blob/main/docs/HARD_MODE_ACCEPTANCE.md)

Launcher 0.4.0의 디자인·설치/롤백·호환성 검사 동작은 변경하지 않았습니다.
