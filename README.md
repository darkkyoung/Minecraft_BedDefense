# Bed Defense

Minecraft Java **26.3 / Fabric / Java 25** — Phase R1 + Hard Raid Balance Playtest (alpha.8).

100일 안에 스폰 침대를 지키고 엔더 드래곤을 처치하는 생존 챌린지입니다.

1. 테스트용 새 월드에서 채팅의 **[게임 시작]** 또는 `/beddefense`를 엽니다.
2. 난이도, 시작 시 월드 시간, 레이드 **편성 진행 배속**을 선택합니다. [설정 완료 · 시작] 선택 시 **3초 동안 모험 모드**로 전환됩니다. 정상 시작이 확정되면 **참가자 인벤토리·장비·보조 손·커서 아이템을 초기화**하고 서바이벌 모드로 시작합니다. 게임모드/아이템 제거에 대한 시스템 채팅은 나오지 않습니다. **어려움** 선택 시 초반 물량·화염 저항·강화 장비·10일차 신속 III·아기 좀비가 적용되는 실험용 편성을 사용합니다. alpha.8의 새로운 어려움 도전에서는 레이드마다 몬스터 수를 지정 범위에서 한 번 추첨하며, 공성 파괴/설치 시간이 이전 어려움보다 완만해졌습니다. **쉬움**은 기존 몬스터 편성을 보존하고 채굴 시간을 50% 줄였습니다. **보통**은 아직 별도 재설계 전의 기존 편성을 유지합니다.
3. 오버월드 침대를 우클릭해 고유 스폰 침대로 지정합니다. 낮에도 가능하며 다른 일반 침대로는 수면·리스폰을 지정할 수 없습니다.
4. 매일 밤 레이드가 등장합니다. ×2는 실제 1·2·3일차에 편성 1·3·5를 적용합니다. 침대를 등록하지 않아도 레이드는 발생합니다.
5. 침대 HP는 100입니다. 에메랄드·다이아몬드 우클릭으로 수리하고, 본인이 부수면 고유 아이템으로 회수해 HP를 유지하며 재설치할 수 있습니다.
6. 침대 미등록·회수·영구 파괴 상태에서 죽으면 탈락합니다. 네더·엔드 사망은 침대 HP 20 감소, 그 죽음으로 HP가 0이면 마지막 리스폰 1회만 허용합니다.
7. 드래곤을 처치하면 승리합니다. 101일차 시작 또는 모든 참가자 탈락 시 실패하고 타이머가 멈춥니다.

상단 중앙 HP 게이지와 남은 레이드 수, 위험 상태 하트, 액션바 경고가 서버 상태를 표시합니다. 몬스터는 각자 가까운 플레이어/침대를 선택하고 장애물을 채굴하거나 발판을 설치합니다. 오버월드 잔여 레이드는 아침 즉시 정산·제거되며 네더·엔드에서는 누적됩니다.

**개발 빌드:** 자동 서버 GameTests와 사람의 실제 그래픽·소리·100일 전투 체감 검증은 구분합니다. Physical Acceptance Pending 항목과 테스트 절차는 [R1 검증 안내](docs/R1_ACCEPTANCE.md)를 확인하십시오. 기존 진행 중인 도전은 기존 프로필로 고정되며, **alpha.8 어려움 랜덤 레이드/공성 조정은 신규 챌린지에서만** 적용합니다. **새 챌린지 및 동일 월드 재시작 시에도 인벤토리를 초기화**하되 월드 건축물·엔더 상자·경험치는 유지합니다. 카운트다운 실패·중단 시 아이템은 삭제되지 않습니다. 미처치/수리/차원 사망 수치는 조정 가능한 임시값입니다. **어려움은 실험적 난이도로 실플레이 밸런스·수중 경로 탐색·기둥 대응 검증이 남아 있습니다.**

## Bed Defense Launcher (Windows)

**Windows 11 x64 자동 설치/업데이트 도구**는 [Releases](https://github.com/darkkyoung/Minecraft_BedDefense/releases)의 최신 `dev-mc26.3-…` 배포에서 **BedDefense-Setup.exe** 하나를 받으시면 됩니다. .NET 별도 설치와 매번 Actions ZIP 다운로드가 필요 없습니다.

1. 기존 **Fabric 26.3 프로필**을 공식 Minecraft Launcher에서 한 번 실행하고, 게임과 런처를 모두 종료합니다.
2. EXE를 열고 **기존 Fabric에 설치 (기본)** → 원하는 프로필을 선택합니다. 표시되는 **실제 게임 폴더**를 확인하고 **설치**를 누릅니다. `gameDir`가 없으면 Minecraft 기본 폴더를 사용합니다.
3. **공식 런처 열기** → 방금 선택한 기존 프로필로 플레이합니다. 이름·ID·게임 경로·실행 버전은 변경하지 않으며 신규 프로필도 만들지 않습니다.
4. 이후 같은 EXE에서 **업데이트 조회 → 업데이트 설치**를 누릅니다. 이미 수동 설치한 Bed Defense JAR이 하나 있으면 그 이름을 유지한 채 백업 후 교체합니다.

기존 환경에서는 **Bed Defense JAR만 다운로드·교체**합니다. 호환되는 Fabric Loader/API는 재사용하며, 누락·버전 불일치·중복·선언된 충돌은 구체적인 원인을 표시하고 설치를 중단합니다. Loader/API를 자동 변경하거나 다른 모드를 삭제하지 않습니다. 같은 `gameDir`를 공유하는 다른 프로필에도 해당 모드가 적용되므로 표시 경로를 확인하십시오. 26.2용 AllBlocks 등 호환되지 않는 모드가 같은 폴더에 있으면 설치하지 않습니다.

**독립 환경에 설치**는 선택 옵션으로 유지됩니다. 이때만 `<Minecraft 폴더>\instances\BedDefense_26.3`과 별도 프로필, Loader 0.19.5 / API 0.163.0+26.3을 구성합니다. **이전 독립 설치에서 기존 Fabric으로 전환** 버튼으로 대상을 바꿀 수 있습니다. 이전 환경·프로필·월드는 삭제하거나 이동하지 않습니다. 월드 이동은 자동으로 수행하지 않습니다.

지원 게임은 **26.3/dev**입니다. 기존 환경의 Loader는 Bed Defense의 `>=0.19.5` 조건과 각 모드의 선언을 검사하며, API는 설치된 버전의 Minecraft·Loader·모드 의존성을 검사합니다. Java 25는 공식 런처가 관리합니다. 메타데이터 검사는 실제 게임 구동 검증을 대체하지 않습니다.

이전 **L3는 런처 화면 업데이트**이며, alpha.8에서는 별도로 게임 내 어려움 레이드 밸런스를 변경합니다. 기존 런처의 **런처 업데이트**를 누르거나 최신 Release의 새 EXE를 받으십시오. 다크/라이트 테마, 침대 방어 배너, 큰 설치·실행 버튼과 붉은 침대 아이콘이 적용됩니다. 런처 설치·복구 엔진은 그대로이며, 게임 모드만 별도 변경되었습니다. 개발 EXE는 아직 코드 서명되지 않았습니다.

## 개발 및 검증

- Java 25, Gradle 9.7.1: `gradle build` (컴파일, 단위 테스트, 격리된 Minecraft/Fabric 서버 GameTests).
- 테스트 전용 소스는 배포 JAR에 포함하지 않습니다. 기존 런처 Windows 안전성·WPF·배포 검증은 유지합니다.
- 관리자 테스트 명령은 `/beddefense debug` 아래에만 있습니다. 별도 `/bdhud` 별칭은 없습니다.
