## Bed Defense 모드 0.2.0-alpha.10+26.3 — 시작 안내 채팅 잘림 개선

- **처음 접속 시 베드 디펜스 환영 안내**를 화면의 위아래 내용이 잘리지 않도록 더 높은 채팅창으로 표시합니다.
- **[게임 시작]**을 눌러 설정 메뉴로 이동하면 즉시 평소 채팅 크기로 돌아갑니다.
- **사용자 채팅 높이 설정은 변경하거나 저장하지 않습니다.** `/beddefense`로 시작 전 안내를 다시 열어도 동일합니다.
- 기존 3초 카운트다운, 모험 모드 → 아이템 초기화 → 서바이벌 전환, 어려움 랜덤 레이드와 공성 밸런스는 그대로 유지됩니다.
- 클라이언트 자동 테스트와 스크린샷 검증을 추가했으며, 실제 사용자 환경의 GUI 배율·셰이더 확인은 별도입니다.

### 런처 업데이트
Minecraft와 공식 런처를 종료하고 기존 **Bed Defense Launcher → 업데이트 조회 → 업데이트 설치**를 이용하세요. Fabric 26.3 프로필에 모드 JAR만 업데이트하며, 월드·다른 모드·설정은 보존합니다. 런처 EXE를 다시 받을 필요는 없습니다.
